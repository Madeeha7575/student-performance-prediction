**Student Performance Prediction**

A Machine Learning project that analyzes student academic performance and predicts writing scores using math and reading scores.

**Project Overview**

This project explores the relationship between student performance across different subjects and identifies factors that influence academic outcomes.

**The project includes:**

Data preprocessing

Exploratory Data Analysis

Data visualization

Correlation analysis

Machine Learning using Linear Regression

Model evaluation using R² Score

Dataset

The dataset contains information about student performance, including:

Gender

Race/Ethnicity

Parental Level of Education

Lunch Type

Test Preparation Course

Math Score

Reading Score

Writing Score

Technologies Used

Python

Pandas

Matplotlib

Seaborn

Scikit-Learn

Exploratory Data Analysis

Average Scores by Subject


Average Scores

Observation: Reading achieved the highest average score among all subjects.

Gender Performance

Observation: Male students scored higher in Mathematics, while female students performed better in Reading and Writing.

Test Preparation Impact

Observation: Students who completed the test preparation course achieved higher average scores across all subjects.

Correlation Heatmap

Observation: Strong positive correlations exist between Reading, Writing, and Overall Average Scores.

Actual vs Predicted

The scatter plot shows a strong relationship between actual and predicted writing scores, indicating that the model performs well on unseen data.

Results:

->Reading had the highest average score (69.17).

->Students who completed the test preparation course performed significantly better across all subjects.

->Female students achieved a higher overall average score than male students.

->Reading and Writing scores showed a very strong positive correlation (0.95).

**Model Performance**

R² Score: 0.9018

This means the model explains approximately 90.18% of the variability in writing scores using math and reading scores.
